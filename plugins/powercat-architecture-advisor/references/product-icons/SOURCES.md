# Product icon sources

These SVG files are unmodified copies of Microsoft-published product artwork for use in architecture documentation.

- `PowerApps_scalable.svg`, `PowerAutomate_scalable.svg`, `PowerPages_scalable.svg`, `Dataverse_scalable.svg`, and `CopilotStudio_scalable.svg` are from the official Power Platform scalable icon pack linked at https://learn.microsoft.com/power-platform/guidance/icons.
- `power_bi_48_color.svg` is from the official Microsoft Fabric icon pack linked at https://learn.microsoft.com/fabric/fundamentals/icons.

Do not crop, rotate, recolor, distort, or use these icons to represent a non-Microsoft product or service. Keep the product name beside each icon. See `../product-icon-spec.md` for rendering requirements.
