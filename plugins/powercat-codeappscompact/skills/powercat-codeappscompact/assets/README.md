# CodeAppsCompact v3.1R

Prebuilt React/TypeScript controls for Power Apps Code Apps. Runtime package version: `3.1.0-r.1`. Keep this package in the app-local vendor folder; no source repository or runtime rebuild is needed.

Configure the bundled workspaces, `RecordFlow`, fields, tables, display cells and data adapters. Use `FormChoice` for closed sets, `FormSelect` for optional/related choices and shared `Modal` focus handling. Import `codeappscompact/theme.css` followed by `codeappscompact/aggregate.css`. Domain rules and confirmed-save callbacks remain app-owned.

Peers: React >=18.3.1 <20, TanStack React Query >=5.90.5 <6 and Power Apps SDK ^1.5.0. Skill tools require Node >=22.18. Browser-local data is synthetic, unencrypted and not authentication or shared production storage. Real bindings require approval and platform permissions.
