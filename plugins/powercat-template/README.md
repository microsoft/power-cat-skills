# powercat-template

Apply the official Power CAT template to presentations, documents, apps, and other branded assets.

## Skills

- **powercat-template** - Inspect the official template and reuse its layouts for presentations or adapt its visual identity for documents and accessible, responsive apps.

## Usage

- "Use the Power CAT template to create a presentation about our project."
- "Create a project brief document using Power CAT branding."
- "Apply the Power CAT template's visual identity to this app."

## Notes

- Canonical template: https://github.com/microsoft/power-cat-skills/blob/main/Common/PowerCAT%20Template.pptx
- Direct download: https://raw.githubusercontent.com/microsoft/power-cat-skills/main/Common/PowerCAT%20Template.pptx
- The template is retrieved when needed, not bundled. Internet access is required unless the user supplies an accessible copy.
- This instruction-only skill complements the host's available presentation, document, or app-building workflow; it does not install those capabilities.
- Derive visual choices from the inspected template, preserve the original, and disclose necessary adaptations or font substitutions.
- Reuse branding only where authorized. The skill does not grant rights to logos or artwork.
- Invoking this skill does not authorize publishing, deployment, or sharing.
