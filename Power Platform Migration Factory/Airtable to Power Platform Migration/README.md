# Airtable to Power Platform Migration

This folder is reserved for the Airtable to Power Platform migration track in the Power Platform Migration Factory.

The track should help teams:

- Extract Airtable schema, relationships, views, automations, and sample data.
- Map Airtable bases to Dataverse tables, columns, relationships, choices, and security.
- Translate Airtable interfaces and workflow intent into Power Apps and Power Automate patterns.
- Validate migration readiness before moving production data.
- Scaffold a Dataverse-backed Power Platform implementation path.

Use this folder for public-facing guidance, samples, scripts, and skill assets related to Airtable modernization.
