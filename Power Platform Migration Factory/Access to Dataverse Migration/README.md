# Access to Dataverse Migration

> **Coming soon**

This folder is reserved for the Access to Dataverse migration track in the Power Platform Migration Factory.

The track should help teams:

- Inventory Access tables, queries, forms, reports, macros, and VBA dependencies.
- Separate data migration from app modernization decisions.
- Propose a Dataverse schema with relationships, ownership, security roles, and environment settings.
- Identify unsupported or high-risk Access behaviors before migration.
- Produce implementation assets that can become a Dataverse solution and model-driven app.

Use this folder for public-facing guidance, samples, scripts, and skill assets related to Access modernization.
