Assumptions and limitations

The user model gives every user the same workload on each active day. Premium overage is calculated per user per modeled 24-hour period, never by subtracting a tenant-wide monthly allowance. Uneven usage or rolling 24-hour peaks can change the bill. Model distinct cohorts separately or use known billable calls for greater accuracy.

Formula: daily calls/user = launches x (1 + additional calls). Monthly billable calls = days x [(users - Premium users) x daily calls + Premium users x max(0, daily calls - available allowance)] + other billable calls. Runtime credits = billable calls x 0.1. Total credits add only the optional amounts you enter; cost = total credits x your USD rate.

This is a planning calculator, not a Microsoft quote, billing connection, or license recommendation. Number of apps alone does not determine cost. Monthly amounts should represent the same planning month.
