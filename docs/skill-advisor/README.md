# Power Platform Skills Advisor

The Power Platform Skills Advisor is a quick-reference map for discovering and using published AI skills, plugins, and MCP capabilities across Power Platform.

Built by the Power CAT team as the **Voice of Engineering to customers**, the portal showcases modern AI ways of working and helps makers, developers, business leaders, and Center of Excellence (CoE) teams find relevant capabilities for their day-to-day work.

**[Open the Skills Advisor portal](https://microsoft.github.io/power-cat-skills/skill-advisor/)**

The portal and section links below use the intended GitHub Pages address. They become available after this contribution is merged and successfully deployed through GitHub Pages; creating a pull request alone does not publish the site.

GitHub controls how README links open. To open the portal in a new tab, use Ctrl+click (Windows), Cmd+click (Mac), or your browser's "Open link in new tab" option.

## CoE team-based skills mapping

The [CoE Team & Roles](https://microsoft.github.io/power-cat-skills/skill-advisor/#coe-roles) view connects skills to the people who govern, build, and support Power Platform solutions.

Its five-stage Value Stream Delivery Pipeline and interactive Flight Deck connect **Governance Gatekeepers** and **Developer Guilds**. Explore the CoE personas and their curated role recipes to identify relevant skills, clarify responsibilities, and plan collaboration across your team.

Use this mapping as a starting point for team enablement and delivery planning, not as a replacement for your organization's governance policies or role definitions.

## Global filters and search

Use **Global Filter** in the portal header to narrow the catalog:

| Filter | Purpose |
| --- | --- |
| **Focus area** | Focus on a product or capability area. |
| **Marketplace** | Narrow results to a source marketplace. |
| **Type** | Select All, Skill, or MCP. |
| **Maturity** | Select All, GA, or Preview. |

The catalog distinguishes **Skills**, **MCP capabilities**, and **References**; references provide supporting guidance rather than executable skills. Reference is not a separate option in the Type filter.

Use global search to find skills, categories, and CoE roles. If a view has no matching skills, use **Remove Global Filter** or **Adjust Global Filter** to broaden your selection.

## Use it in your day-to-day work

1. **Start with the task.** Open [Mission Control](https://microsoft.github.io/power-cat-skills/skill-advisor/#mission), a product view, or your [CoE role](https://microsoft.github.io/power-cat-skills/skill-advisor/#coe-roles) to find capabilities relevant to the work ahead.
2. **Review the details.** Read the capability description, maturity, source documentation, and any available usage examples.
3. **Set up the required tools.** Follow the linked plugin or skill documentation for the supported host, installation steps, permissions, licenses, and environment prerequisites.
4. **Apply and review.** Use the skill in its supported AI tool, provide the relevant project context, and review its output before applying changes to your solution or environment.

For example, a developer can use the portal to discover assistance for designing a solution, building an app or flow, working with Dataverse, reviewing quality, and preparing for governance and deployment.

The portal is a discovery and reference experience: it does not install plugins or execute skills itself. Availability and behavior depend on the underlying skill, supported tool, and environment. Usage examples are starting points, not production certification.

## Maintenance and updates

The portal is intended to receive weekly catalog updates as Microsoft publishes skills.
