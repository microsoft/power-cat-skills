Get started

Install the marketplace, then install the plugins you need.

Use Microsoft Scout or GitHub Copilot CLI to register the marketplace and add the Power CAT plugins for your workflow.

Register the marketplace

copilot plugin marketplace add microsoft/power-cat-skills

Install a plugin

copilot plugin install powercat-canvas-apps@power-cat-skills

Use a skill

Analyze my Canvas App for performance issues
